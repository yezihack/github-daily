# 工单 03 验收检查清单

## 浏览器人工验收步骤

### 1. 桌面端验收（1920×1080）

#### 1.1 全屏布局
- [ ] 打开浏览器，设置视口为 1920×1080
- [ ] 访问 `http://localhost:5173` (或开发服务器地址)
- [ ] **验证：** 六张卡片以 3×2 网格铺满整个视口
- [ ] **验证：** 页面本身无垂直滚动条（body 不滚动）
- [ ] **验证：** 页面本身无水平滚动条

#### 1.2 卡片独立滚动
- [ ] 在每张卡片内向下滚动
- [ ] **验证：** 每张卡片内部可以独立滚动
- [ ] **验证：** 滚动一张卡片时，其他卡片不受影响
- [ ] **验证：** 如果榜单有 25 条数据，可以滚动到第 25 条
- [ ] **验证：** 滚动到底部时不会触发页面滚动（overscroll-behavior 生效）

#### 1.3 榜单配色
- [ ] **日榜**：蓝色 (#7aa2f7) 顶部边框和标题
- [ ] **周榜**：紫色 (#bb9af7) 顶部边框和标题
- [ ] **月榜**：黄色 (#e0af68) 顶部边框和标题
- [ ] **年榜**：粉红色 (#f7768e) 顶部边框和标题
- [ ] **当日提及榜**：青色 (#7dcfff) 顶部边框和标题
- [ ] **GitHub 趋势历史榜**：橙色 (#ff9e64) 顶部边框和标题
- [ ] **验证：** 六个榜单配色互不相同，一眼可分辨

#### 1.4 荧光绿信号色
- [ ] 在有 `gained` 数据的条目中查看增长数
- [ ] **验证：** 增长数（↑ 数字）使用荧光绿色 (#c8f751)
- [ ] **验证：** 增长数的颜色比其他指标更醒目
- [ ] **验证：** stars、forks 等其他指标不使用荧光绿

#### 1.5 等宽字体
- [ ] 查看榜单排名（rank）数字对齐
- [ ] 查看 stars、forks、gained 等指标数字
- [ ] **验证：** 所有数字使用等宽字体（Consolas 或 monospace）
- [ ] **验证：** 数字垂直对齐整齐（font-variant-numeric: tabular-nums）

#### 1.6 中文字体回退
- [ ] 打开浏览器开发者工具 → Network 标签
- [ ] 刷新页面
- [ ] **验证：** 没有外部字体文件请求（无 .woff2, .woff, .ttf 等）
- [ ] **验证：** 中文文本正常显示（使用系统字体）
- [ ] **验证：** 即使在弱网环境下，中文排版不会塌陷

#### 1.7 顶栏骨架
- [ ] **验证：** 顶栏左侧显示「TrendShift」和「中文看板」
- [ ] **验证：** 顶栏右侧有「期次（UTC）」标签和日期选择器
- [ ] **验证：** 顶栏右侧有「数据状态」标签和状态显示
- [ ] **验证：** 顶栏固定在页面顶部，不随页面滚动

#### 1.8 无入场动画
- [ ] 刷新页面多次
- [ ] **验证：** 卡片和内容立即显示，无淡入、滑入等动画效果
- [ ] **验证：** 内容可立刻阅读，无等待动画完成

#### 1.9 Fullscreen API 未调用
- [ ] 打开浏览器开发者工具 → Console
- [ ] 在 Console 输入: `document.fullscreenElement`
- [ ] **验证：** 返回 `null`（未进入全屏状态）
- [ ] **验证：** 页面使用 CSS `100vh` 布局，不是浏览器全屏 API

---

### 2. 移动端验收（< 720px）

#### 2.1 单列布局
- [ ] 调整浏览器窗口宽度到 720px 以下（或使用移动设备）
- [ ] **验证：** 六张卡片改为单列纵向排列
- [ ] **验证：** 页面可以纵向滚动
- [ ] **验证：** 每张卡片宽度占满容器

#### 2.2 卡片内容可读
- [ ] 在移动端查看每张卡片
- [ ] **验证：** 卡片内容完整显示，无横向滚动
- [ ] **验证：** 文字大小适中，可正常阅读
- [ ] **验证：** 卡片内部内容不滚动（overflow: visible）
- [ ] **验证：** 所有 25 条数据都可见（通过页面滚动访问）

#### 2.3 顶栏适配
- [ ] **验证：** 顶栏在移动端自动换行（flex-wrap）
- [ ] **验证：** 所有控件仍然可见和可用

---

### 3. 交互验收

#### 3.1 可点击性
- [ ] 点击任意榜单条目
- [ ] **验证：** 可以打开详情抽屉（如果已实现）
- [ ] 使用键盘 Tab 键聚焦到条目
- [ ] 按 Enter 或空格键
- [ ] **验证：** 键盘操作也能触发详情

#### 3.2 悬停反馈
- [ ] 鼠标悬停在榜单条目上
- [ ] **验证：** 背景色有轻微变化
- [ ] **验证：** 鼠标指针变为 pointer（可点击状态）
