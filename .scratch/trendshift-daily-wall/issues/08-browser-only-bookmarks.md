# 08: 收藏（纯浏览器）

**Status:** ✅ **已完成**

**What to build:** 访客无需登录即可收藏感兴趣的**仓库**，刷新页面后仍在；顶栏「只看收藏」切到独立列表视图，已经掉出所有**榜单**的**仓库**依然完整可见。全程不产生账号、不产生服务端用户数据。本任务只依赖抽屉，可与 AI 链并行开展。

**Blocked by:** 05 详情抽屉（元数据版）

**Completed:** 2026-11-13

- [x] 抽屉里可收藏 / 取消**仓库**，无需登录、无需配置任何东西
- [x] 浏览器本地存储只存归一化标识 + 收藏时间，不存解读正文、不存任何用户身份
- [x] 刷新页面后**收藏**仍在；界面明确提示「仅保存在此浏览器」
- [x] 顶栏「只看收藏」切到独立列表视图，而不是把当期六张卡片过滤一遍
- [x] 掉出所有**榜单**的**仓库**仍出现在**收藏**列表，且能看到其**中文解读**（若已生成）
- [x] 批量换详情用 POST + JSON body，不携带用户身份；不合法请求返回 400
- [x] 接近 500 条时给出清理提示；本地存储不可用时降级为内存态并提示
- [x] D1 中不出现用户表或**收藏**表
- [x] 浏览器人工验收通过；不引入 Playwright 自动化缝
