# 中文解读由服务端 Cron 预生成，密钥不出 Worker

**中文解读**属于**仓库**、全站共享一份，因此由 Worker 的分钟级 Cron 从 D1 待办队列每批 10 个调用 OpenAI 兼容的 `/chat/completions`，生成简介 / 解决问题 / 适用人群三段后落库；访客只读 D1，API 密钥只存在 `wrangler secret`。三段缺一即视为解读未完成，界面显示英文原文与「解读生成中」角标，不把半截内容写进 D1。

**Considered Options**: 首次访问按需生成（全屏 150 条会引发并发调用与首访等待）、浏览器直连 AI（每访客需自备密钥、无法共享解读）、离线脚本预生成（更新依赖重新部署）。
