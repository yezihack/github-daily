# Triage 状态词表

技能以五个规范角色描述 triage 状态。本表把它们映射到本仓库实际使用的字符串。

| 角色（mattpocock/skills） | 本仓库标记 | 含义                           |
| ------------------------ | ---------- | ------------------------------ |
| `needs-triage`           | `待评估`   | 维护者需要评估                 |
| `needs-info`             | `待补充`   | 等报告人补充信息               |
| `ready-for-agent`        | `可自动开发` | 规格完整，AFK agent 可直接接手 |
| `ready-for-human`        | `需人工`   | 需人工实现                     |
| `wontfix`                | `不修复`   | 不处理                         |

技能提到某个角色时（例如「打上 AFK-ready 的 triage 标记」），使用上表右列的字符串。
