# 02: 六榜全量采集与归一化

**What to build:** 访客一次采集就能看到六个**榜单**各 25 条，不再只有日榜。三类不同的 RSC 载荷形态都能正确解析，各榜该有的指标都在，界面按六组呈现。这是把 `01` 的单榜通道扩展到完整数据源，仍不改界面布局形态。

**Blocked by:** 01 最薄端到端：日榜真实数据上屏

**Status:** 可自动开发

- [ ] 一次采集返回六个**榜单**、每榜 25 条（共 150 条）；中文名称与顺序固定：日榜 / 周榜 / 月榜 / 年榜 / 当日提及榜 / GitHub 趋势历史榜
- [ ] 日/周/月/年榜从 `initialData` 取数，趋势历史榜从 `repositories` 取数，当日提及榜从 `initialMentions` 取数；任一缺失则该榜为空并留下警告
- [ ] 每条含 rank、stars、forks、gained 或 featured、语言与标签；趋势历史榜以 watchers 作 stars、featured_count 作 featured；当日提及榜无 gained
- [ ] `gained > stars` 按上游原值展示，不做修正
- [ ] 六榜共享同一份**仓库**记录；同一仓库跨榜不重复建**仓库**、不重复存地址
- [ ] 界面按六组展示，每组可看到全部 25 条
- [ ] 测试夹具覆盖三类载荷，HTTP 缝断言六榜条数与字段；`01` 既有测试仍绿
- [ ] 榜单元数据与响应契约由前后端共享，界面文案不把**榜单条目**称作**仓库**
