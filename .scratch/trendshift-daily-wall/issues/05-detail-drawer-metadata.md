# 05: 详情抽屉（元数据版）

**What to build:** 访客点开任一条目，右侧抽屉显示英文原始简介、该**期次**的完整指标、GitHub 外链、复制地址与项目主页第二外链，并标注**期次**日期；随时可关闭回到看板。**中文解读**的位置此时仍显示待生成状态，不给空白也不给假内容。

**Blocked by:** 03 全屏六榜卡片墙；04 期次与 UTC 日期回看

**Status:** 可自动开发

- [ ] 点条目打开抽屉，显示英文原始简介、rank / stars / forks / gained 或 featured / 语言 / 标签，取值均来自**当期榜单条目**
- [ ] 抽屉显示**期次**日期并标 `UTC`；回看历史时指标仍是那一期的
- [ ] GitHub **仓库**地址可点开；复制地址按钮把地址写入剪贴板并给出短暂成功反馈
- [ ] 项目主页存在时提供第二外链，不存在时不显示空链接
- [ ] 抽屉可关闭并回到全屏看板
- [ ] 抽屉不出现**中文解读**正文；该区域显示待生成状态而非空白
- [ ] 界面文案明确「指标跟随**榜单条目**、解读跟随**仓库**」这一边界，不把两者混为一谈
- [ ] 浏览器人工验收通过
