# 07: 无人值守解读队列与失败降级

**What to build:** 不再需要人工触发：每日采集之后，**中文解读**会在约 10–15 分钟内自动补齐；遇到坏简介会自动找 README 兜底；反复失败的**仓库**有界重试后显示英文原文与角标，而不是拖住队列或露出半截中文。

**Blocked by:** 06 AI 三段解读最小闭环

**Status:** 可自动开发

- [ ] 每日 UTC 00:10 采集六榜；分钟级定时任务从 D1 待解读队列每次最多处理 10 个**仓库**，未处理完由后续触发续跑
- [ ] 冷启动后 10–15 分钟内所有唯一**仓库**都有完整的三段解读
- [ ] 英文简介为空、过短、乱码或来自当日提及榜时，抓取 README 并截断 3000 字兜底；README 抓取失败退回纯元数据且不阻塞
- [ ] AI 未配置、超时、限流、坏 JSON、缺段或长度越界：不写 D1，重试计数加一，累计 3 次后标记失败
- [ ] 未完成或失败的**仓库**在卡片显英文原文 + 「解读生成中」或「解读暂缺」角标，绝不显半截中文
- [ ] 失败项状态可重新入队（触发端点在 `09` 交付），已完成解读不被重复处理
- [ ] 同日多次触发不产生重复 AI 调用
- [ ] HTTP 缝断言三次重试、失败标记与角标数据；夹具覆盖空壳简介与 README 抓取失败
