# 09: 运维端点与鉴权

**What to build:** 运维可以用令牌保护的三个端点手动触发采集、重跑失败解读、查询状态；部署完空库时可立刻手动触发一次让首页有数据，不必等第二天；公开读取带上缓存头。匿名访客依然没有任何写操作入口。

**Blocked by:** 07 无人值守解读队列与失败降级

**Status:** 可自动开发

- [ ] 三个管理端点校验 `ADMIN_TOKEN`：无令牌返回 401，带令牌返回 200
- [ ] 采集触发端点可手动重抓六榜；重跑端点把失败解读重新入队；状态端点返回采集与解读状态
- [ ] 冷启动（D1 无任何**期次**）时，按部署说明手动触发一次即可让首页有数据
- [ ] 公开读取接口带缓存头：历史**期次**长缓存、最新一期短缓存
- [ ] 更换 AI 供应商或模型只改部署配置变量/密钥，不改代码、不重新构建前端
- [ ] 首页不出现刷新按钮；运维入口只在部署说明中给出
- [ ] 部署说明覆盖 D1 创建与绑定、静态资源目录、两条定时任务、密钥配置与冷启动步骤
- [ ] 匿名访客没有任何写操作入口；不配置 CORS、不引入限流
- [ ] HTTP 缝断言 401 / 200 与缓存头
