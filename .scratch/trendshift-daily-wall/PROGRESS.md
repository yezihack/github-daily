## 🚀 部署与验收

### 快速开始

```bash
# 安装依赖
npm install

# 本地开发
npm run dev

# 构建部署
npm run build
npm run deploy

# 测试验收
npm run test
```

### 冷启动流程

1. 部署到 Cloudflare Worker
2. 创建 D1 数据库并执行 migrations
3. 配置环境变量：
   - `ADMIN_TOKEN`：管理端点令牌
   - `AI_BASE_URL`、`AI_API_KEY`、`AI_MODEL`：AI 配置（可选）
4. 手动触发一次采集：
   ```bash
   curl -X POST https://your-worker.dev/api/admin/ingest \
     -H "Authorization: Bearer YOUR_ADMIN_TOKEN"
   ```
5. 等待 10–15 分钟，解读自动补齐
6. 访问 https://your-worker.dev 查看榜单

### 运维常用命令

```bash
# 查询采集和解读状态
curl https://your-worker.dev/api/admin/status \
  -H "Authorization: Bearer YOUR_ADMIN_TOKEN"

# 重跑失败的解读
curl -X POST https://your-worker.dev/api/admin/interpretations/retry \
  -H "Authorization: Bearer YOUR_ADMIN_TOKEN"

# 查询公开榜单数据（带缓存）
curl https://your-worker.dev/api/boards
curl https://your-worker.dev/api/boards?date=2026-11-13

# 批量查询收藏的仓库详情
curl -X POST https://your-worker.dev/api/repos/bulk \
  -H "Content-Type: application/json" \
  -d '[{"owner":"owner1","name":"repo1"}]'
```

| 特性 | 说明 |
| --- | --- |
| **全自动采集** | 每日 UTC 00:10 自动采集六榜，无需人工干预 |
