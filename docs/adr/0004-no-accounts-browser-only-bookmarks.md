# 无账号，收藏只存在于浏览器

产品不设账号，收藏只以 `owner/name` + 收藏时间存在访客浏览器的 `localStorage`；D1 只保存**榜单**、**期次**、**榜单条目**与**仓库**，不建用户表或收藏表。之所以「有 D1 却没有收藏表」，是为了让访客零摩擦收藏且不产生任何用户数据；代价是换浏览器或清缓存即丢失，界面明确提示「仅保存在此浏览器」。收藏列表按标识批量向 D1 换取**仓库**详情，因此**仓库**掉出榜单后仍可查看，服务端也不因掉榜删除仓库。

**Considered Options**: 匿名账号 + 服务端收藏表（可跨设备同步，但要引入身份、隐私说明与写接口）、浏览器存完整解读快照（离线可看，但解读修正后不会更新）。
