# 10: 采集容错与数据状态可见

**What to build:** 上游返回坏页面、某个**榜单**解析为空、或首次部署还没有数据时，访客看到的仍是一个可读的页面和准确的数据新鲜度说明，而不是空白或误导；顶栏把「更新于 X 日 UTC」「解读生成中 N 项」显示出来。这是把所有降级口径收口并做全链路验收的最后一环。

**Blocked by:** 03 全屏六榜卡片墙；09 运维端点与鉴权

**Status:** 可自动开发

- [ ] 首包 HTML 缺 RSC 载荷时以 `RSC: 1` 请求头重试一次；仍失败则该**榜单**沿用上一**期次**，其余**榜单**照常写入
- [ ] 单个**榜单**解析为 0 条时该榜沿用上一**期次**并标出数据日期
- [ ] 顶栏显示「更新于 X 日 UTC」与「解读生成中 N 项」
- [ ] 沿用上一**期次**时响应里带数据新鲜度状态，界面角标可见
- [ ] 首次部署或 D1 无数据时显示明确空状态与手动触发采集的指引
- [ ] 任何降级都返回可用数据而非空结果；不删历史、不隐藏条目、不伪装成已解读
- [ ] 桩返回不含 RSC 的空壳时，HTTP 缝断言沿用上一**期次**与状态字段
- [ ] 全链路验收对齐 spec 的 22 条验收标准
- [ ] 术语表与四条 ADR 的约束在接口字段、界面文案与测试断言中保持一致
